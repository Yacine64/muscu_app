# muscu_app

Application web personnelle (PWA) pour suivre ses entraînements de musculation sur Android, hors ligne. Toutes les données restent sur le téléphone.

- App en ligne : https://yacine64.github.io/muscu_app/
- Résumé du projet, stack et commandes : voir [CLAUDE.md](CLAUDE.md)

```bash
npm install
npm run dev     # développement
npm test        # tests
npm run build   # build de production
```
